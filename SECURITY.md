# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Send a private report to **daudtasleem215@gmail.com** with:

1. A description of the vulnerability and its potential impact.
2. Steps to reproduce (minimal example preferred).
3. Any suggested fix, if you have one.

You will receive an acknowledgement within 48 hours and a status update within
7 days. Once a fix is ready, a patch release will be published and the
vulnerability will be disclosed in the release notes with credit to the
reporter (unless anonymity is requested).

## Scope

This policy covers the `lidar-strip-adjust` Python package and its CLI.
Vulnerabilities in upstream dependencies (numpy, scipy, laspy, etc.) should be
reported directly to those projects.
